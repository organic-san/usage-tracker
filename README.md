# Usage Tracker

一個輕量的桌面小工具,把 **Claude、Gemini** 等官方用量頁面直接嵌入一個常駐視窗,方便隨時盯著額度,並支援定時自動刷新、視窗置頂與開機自啟。

以 [Tauri 2](https://v2.tauri.app/) + Vite 打造,前端為原生 HTML/CSS/JS,後端為 Rust。

---

## 功能特色

- **服務側欄** — 服務以圖示排在左側直欄,數量再多也只是往下排,不會擠壓其他按鈕。拖曳圖示即可調整順序,右鍵開啟選單(重新整理、並排時顯示、編輯)。內建 Claude 與 Gemini,也可自行新增任意網址。
- **登入分身隔離** — 每個服務使用獨立的資料目錄(profile),登入狀態互不干擾,可同時掛多個帳號。
- **並排檢視** — 可指定哪些服務加入並排,選擇 **左右** 或 **上下** 排列;拖曳分隔線調整比例,雙擊分隔線平均分配。
- **自動刷新** — 倒數顯示在標題列,點一下立即刷新,也能暫停 / 繼續。視窗最小化時暫停刷新,還原後補刷新過期的頁面。
- **長時間常駐不累積記憶體** — 畫面上的頁面存活超過 30 分鐘後,下一次刷新會在背景建立全新的頁面程序,載入完成才換上(畫面不會閃白);不在畫面上的頁面超過 30 分鐘直接釋放,切換回來時重新載入。暫停自動刷新時,畫面上的頁面每 2 小時重建一次。
- **視窗置頂** — 釘選視窗讓它永遠顯示在最上層。
- **開機自啟** — 可選擇登入時自動啟動。
- **記住視窗大小與位置** — 重開後自動還原上次的視窗尺寸與位置。
- **無邊框視窗** — 整條標題列與側欄空白處都能拖曳移動視窗,雙擊標題列可最大化。

## 環境需求

- [Node.js](https://nodejs.org/)(建議 LTS 版本)
- [Rust 工具鏈](https://www.rust-lang.org/tools/install)(`rustup` / `cargo`)
- Tauri 的系統相依套件,請依官方指南安裝:<https://v2.tauri.app/start/prerequisites/>
  - Windows 需安裝 **Microsoft C++ Build Tools** 與 **WebView2 Runtime**(Windows 10/11 通常已內建)。

---

## 安裝

```bash
# 取得原始碼後,安裝前端相依套件
npm install
```

> Rust 相依套件會在第一次啟動或建置時由 Cargo 自動下載。

---

## 啟動(開發模式)

```bash
npm run tauri dev
```

會自動啟動 Vite 開發伺服器並開啟桌面視窗,支援前端熱重載。

---

## 打包(正式版)

```bash
npm run tauri build
```

打包完成的安裝檔(Windows 為 NSIS 安裝程式)會輸出在:

```
src-tauri/target/release/bundle/
```

## 使用說明

1. 點側欄的 **+** 新增服務,填入 **名稱** 與 **網址**;「分身(profile)」留空會自動依名稱產生,相同分身代表共用同一份登入狀態。
2. 點側欄圖示切換服務;按側欄下方的並排鈕同時顯示多個服務,旁邊的方向鈕切換左右 / 上下排列。
3. 側欄最下方的 **設定** 可編輯 / 刪除服務、拖曳調整順序、設定刷新間隔、置頂與開機自啟,變更立即生效。
4. 快捷鍵(焦點在本工具介面時):`Ctrl+1`~`Ctrl+9` 切換服務、`Ctrl+R` / `F5` 刷新、`Ctrl+,` 開啟設定、`Esc` 關閉設定。
5. 設定與登入資料分別儲存在系統的 app config / app data 目錄中,**不會**寫入專案資料夾。

> ⚠️ 內建的用量網址為預填值,實際路徑請以各服務官方頁面為準,可在設定中自行修改。

## 程式結構

官方頁面是 Rust 端建立的原生子 webview,永遠蓋在介面的 HTML 之上。因此介面不使用任何浮動元件:
舞台位置由前端以 CSS 決定後回報給 Rust,選單一律使用原生選單,設定頁開啟時先把官方頁面藏起來。

| 位置 | 內容 |
|---|---|
| `src/` | 前端(原生 JS 模組):`topbar` 標題列、`rail` 側欄、`stage` 舞台與分隔線、`settings` 設定頁、`store` 狀態 |
| `src-tauri/src/config.rs` | 設定檔的資料結構、讀寫與正規化 |
| `src-tauri/src/layout.rs` | 並排切分的版面計算 |
| `src-tauri/src/views.rs` | 子 webview 的建立、排版、隱藏、刷新與記憶體回收 |
| `src-tauri/src/scheduler.rs` | 自動刷新與記憶體維護的排程執行緒 |
